# ISS Network Infrastructure Proposal

## Overview

This repository contains a comprehensive network infrastructure proposal for the **International Space Station (ISS)**, developed as the final project for the **Emerging Network Technologies** course taught by **Dr. Krishna Neith Guzmán Benavides**.

The project focused on designing a secure, scalable, and fault-tolerant network architecture capable of supporting communications between ISS modules and ground control stations while integrating emerging networking technologies.

This proposal was recognized as the **best project** among **10 participating teams**, standing out for its technical quality, feasibility, and innovative approach.

---

## Objectives

- Analyze the communication requirements of the International Space Station.
- Design a logical and physical network architecture.
- Implement IPv4 and IPv6 addressing schemes.
- Integrate emerging networking technologies.
- Validate the proposed infrastructure through simulation.

---

## Project Scope

### Research
- ISS architecture and international modules.
- Space-to-ground communication requirements.
- Network design considerations for space environments.

### Network Design
- Logical topology.
- Physical topology.
- Three-layer architecture (Core, Distribution, Access).
- Redundancy and scalability.
- Security considerations.

### IP Addressing
- IPv4 subnetting.
- IPv4+ addressing.
- IPv6 addressing.
- Internal and external network segmentation.

### Emerging Technologies
- Zero Trust Network (ZTN)
- Internet of Things (IoT)
- Edge Computing
- Wireless LAN (WLAN)
- Delay/Disruption Tolerant Networking (DTN)

### Cost Analysis
- Network equipment selection.
- Infrastructure cost estimation.

### Simulation

The network design was implemented and validated using **Cisco Packet Tracer**, verifying:

- End-to-end connectivity.
- Routing.
- Communication between ISS modules.
- Connectivity with ground control stations.
